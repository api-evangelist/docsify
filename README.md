## APIs

### Docsify
Docsify is a lightweight, no-build documentation site generator that turns Markdown files into a website on the fly using client-side JavaScript rendering. It is an open source, MIT-licensed JavaScript library that renders Markdown content in the browser without a build step. Docsify itself does not expose an HTTP/REST API; it is a client-side rendering tool consumed as a JavaScript library.

**Human URL:** [https://docsify.js.org](https://docsify.js.org)
